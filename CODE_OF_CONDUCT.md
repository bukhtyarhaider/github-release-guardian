# Community expectations

Be respectful, patient, and clear, especially when helping someone new to GitHub or coding agents. Discuss behavior and evidence without personal attacks. Harassment, threats, discrimination, doxxing, spam, and publication of another person's private information are not welcome.

Use issues for actionable problems and improvement requests. Keep reports focused on this project and remove credentials or private customer information. Give others room to ask questions and correct mistakes.

Maintainers may edit or remove disruptive content, close off-topic discussions, or restrict participation using GitHub's moderation tools. Apply these decisions consistently and proportionately. Report private security concerns through [SECURITY.md](SECURITY.md); do not reproduce harmful content publicly to report it.
