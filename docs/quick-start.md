# Quick start for a new user

Open your real project in your agent. Ask it to install this package using the guide for [your agent](installation/generic.md). Then say “Inspect my GitHub setup.” Nothing on GitHub changes during inspection.

Read the short plan. Approve the setup you want. Your agent prepares a maintenance review request; an administrator activates protections and hosting access. Ask it to verify an actual testing deployment before announcing readiness.

Say “Start a feature,” “Save my progress,” “Send this for testing,” or “Release the latest tested changes.” You can ask “What happens next?” at any point. Required reviewers approve on GitHub. [Beginner guide](beginner-guide.md).
