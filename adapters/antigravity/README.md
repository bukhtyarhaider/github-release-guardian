# Google Antigravity adapter

Use [the installation guide](../../docs/installation/antigravity.md). `scripts/install.py --agent antigravity` copies the single canonical implementation to the officially documented discovery directory. Use natural language naming GitHub Release Guardian, or `/github-release-guardian` where your installed version supports skill slash invocation. Add `--aliases` for the ten `/github-*` command skills. Antigravity now documents .agents/skills and retains legacy .agent/skills compatibility. Restart or reload skills if your version has not discovered them.

The adapter does not grant tools or credentials. Keep the target app's permission controls and GitHub's required reviews. Verify discovery with a read-only audit before authorizing writes.
