# Codex adapter

Use [the installation guide](../../docs/installation/codex.md). `scripts/install.py --agent codex` copies the single canonical implementation to the officially documented discovery directory. Use `$github-release-guardian` and natural language, such as “Set up my GitHub project.” The ten conceptual /github-* commands are not installed as Codex slash commands.

The adapter does not grant tools or credentials. Keep the target app's permission controls and GitHub's required reviews. Verify discovery with a read-only audit before authorizing writes.
